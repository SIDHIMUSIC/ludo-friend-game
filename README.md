# Ludo Friend Game

Web-based Ludo to play with friends (hotseat - pass the device).

## How to Play
1. Open the site
2. Click "Start / Reset Game"
3. Roll dice (click the dice)
4. Click your token to move
5. Rules: Need 6 to enter from base. Extra turn on 6. Capture opponents by landing on them.

## Secret Environment Feature (Chakali)
Jis color ko jeetana ho, environment me set kar do:

### Console se (recommended)
Browser console open karo (F12) aur type karo:
```js
cheat('red')
```
ya `cheat('green')`, `cheat('yellow')`, `cheat('blue')`

Us color ko dice me zyada 6 aayenge, aur baaki players ko kam. Gradually wo jeetega.

### URL se
```
https://SIDHIMUSIC.github.io/ludo-friend-game/?winner=red
```

**Doston ko mat batana!** Sirf tum set kar lo game start se pehle.
